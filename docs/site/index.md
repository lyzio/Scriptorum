# Scriptorum

Scriptorum is a desktop text processor for game masters who write their own adventures. It produces print-ready PDFs: an adventure PDF for the game master and a separate PDF of player handouts, built from the same text so they never drift apart.

You write in formatted text, much like a word processor, and insert game elements such as scenes, read-aloud texts, people and creatures as framed boxes. People, places and clues live in a codex and are written once. Maps keep their game-master details on layers the players never see. The look of the printed adventure comes from a theme, and everything specific to one game comes from a game system, so both can be swapped without touching the text.

Scriptorum runs on Linux, macOS (12 or newer) and Windows, needs no internet connection, and is free software under the GNU GPL, version 3 or later.
