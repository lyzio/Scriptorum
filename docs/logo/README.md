# The Scriptorum logo

`scriptorum-logo.png` is the original (832 × 832 pixels, RGBA PNG, SHA-256 `4d2c245b9ef6ac51e5c93f85d935b1d65ceca549ecd766b53eb01db2c8cbf585`), chosen by the project manager on 18 November 2026: line art of a scroll, a fountain pen, a split globe and a twenty-sided die, with the SCRIPTORUM ribbon, on a transparent background. It replaced the first logo, on a parchment ground, in 0.7.3. It is drawn straight on the window's background, with no card, border or shadow, and one version serves light and dark mode. The app uses a 512-pixel copy, `scriptorum/ui/logo.png`, in the About window, on the welcome screen and in the start-up window (design document F9, D16). It is never printed in an adventure's PDF. The file icons (app, `.scav`, `.scmod`) in `packaging/icons/` are separate drafts and stay as they are.
