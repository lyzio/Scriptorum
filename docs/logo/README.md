# The Scriptorum logo

`scriptorum-logo.png` is the original (1254 × 1254 pixels), chosen by the project manager on 18 November 2026. The app uses a 512-pixel copy, `scriptorum/ui/logo.png`, in the About window, on the welcome screen and in the start-up window (design document F9, D16). It is never printed in an adventure's PDF. The file icons (app, `.scav`, `.scmod`) in `packaging/icons/` are separate drafts and stay as they are.

The logo was made with an AI image tool. It is licensed under the Creative Commons Attribution-ShareAlike 4.0 International licence (CC BY-SA 4.0), with no personal credit; the full text is in `scriptorum/licences/texts/CC-BY-SA-4.0.txt` and in Help ▸ About Scriptorum ▸ Licences.
